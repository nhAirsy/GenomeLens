# GenomeLens 文档

本目录保存 GenomeLens 的用户文档、开发文档和交付说明。所有文档应保持同一口径：项目完整目标是 2 到任意多个物种的 GFF/FASTA 到多物种美化版 JCVI 共线性图；当前实现范围是 `species[]` 统一入口、双物种真实 JCVI 链路、多物种 all-vs-all pairwise(全组合两两比较) 编排与汇总，以及把成功 pairwise 聚合成一张全局多物种核型总图。

## 文档索引

- `项目介绍.md`：项目完整目标、当前能力、未完成范围和模块边界。
- `使用方法/README.md`：当前 `species[]` 命令行使用方式。
- `使用方法/配置文件说明.md`：`genomelens.config.json` 与 `jcvi.config.json` 的完整字段、示例与优先级。
- `使用方法/JCVI能力与配置.md`：JCVI workflow(工作流)、配置优先级和降级策略。
- `开发手册/README.md`：开发环境、测试和构建入口。
- `开发手册/代码风格规范.md`：项目自有代码的代码风格与 ruff 使用规则。
- `开发手册/结构优化计划.md`：当前结构短板、优化目标与阶段化方案。
- `开发手册/能力接入规则.md`：新增 JCVI 能力时需要同步的协议、测试和文档。
- `开发手册/项目改进意见.md`：已完成整理项、剩余短板与后续优先级。
- `开发手册/架构调整/README.md`：当前架构调整文档索引。
- `开发手册/架构调整/多平台兼容方案.md`：共享核心、多平台薄外壳的运行与发布策略。
- `开发手册/架构调整/最终架构目标.md`：比较基因组学平台、多引擎、Tauri GUI 与 Agent 的长期目标架构。
- `CLI.md`：公开 CLI(命令行接口) 契约。
- `TOOLCHAINS.md`：BLAST+、ImageMagick、jcvi-genomelens 等 runtime toolchain(运行时工具链) 说明。
- `DELIVERY.md`：core package(核心包)、full/offline package(完整/离线包) 和 HAIant 插件交付说明。
- `历史文档/`：已落地或被取代的历史计划与记录（如分析命令改版计划、代码整洁改进建议），仅作追溯，不代表当前待办。
- `施工计划/`：历史施工计划资料，压缩包不进入 Git 跟踪。

## 维护原则

文档只能承诺当前版本真实可运行能力。多物种 pairwise 编排与跨全部物种的全局核型共线性总图可以写成当前能力；全局 layout/seqids 自动优化、最终美化排版、机器学习评分和 Agent 自动调参仍应写在目标或路线中，不能写成当前已支持。
